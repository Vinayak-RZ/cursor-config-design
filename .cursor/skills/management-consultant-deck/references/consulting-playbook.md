# Consulting deck playbook

McKinsey · BCG · Bain · Barbara Minto pyramid principle

## Firm styles (adapt to client brand colors)

| Firm | Signature moves |
|------|-------------------|
| **McKinsey** | Action titles; issue trees; waterfall bridges; "Exhibit N" labels; clean sans serif |
| **BCG** | 2×2 matrices; experience curves; bold section breaks; hypothesis-driven storyline |
| **Bain** | Results orientation; "Net promoter" style metrics; implementation timeline emphasis |
| **Minto** | Answer first; MECE grouping; pyramid structure |

## Deck types

### Strategy recommendation (default)

1. Executive summary — **recommendation in first 3 bullets**
2. Situation — facts all agree on
3. Complication — why change is needed now
4. Key question — single governing question
5. Analysis sections (2–4) — one insight per slide
6. Synthesis — "So what" implications
7. Recommendations — numbered, owner, timing
8. Implementation roadmap — 30/60/90 or waves
9. Risks & mitigations
10. Appendix — detailed exhibits

### Due diligence / market study

- Market size & growth
- Segmentation
- Competitive landscape
- Customer voices
- Regulatory / macro
- Investment thesis / risks

### Board update

- Performance vs plan
- Strategic priorities status
- Decisions needed from board
- Financial snapshot

### Proposal / RFP response

- Understanding of client situation
- Approach & methodology
- Team & credentials
- Timeline & deliverables
- Commercial terms (appendix)

## Slide anatomy (consulting grade)

```text
┌─────────────────────────────────────────────┐
│ ACTION TITLE: Complete sentence insight      │
├─────────────────────────────────────────────┤
│                                              │
│   [Chart / framework / 3 bullets max]        │
│                                              │
├─────────────────────────────────────────────┤
│ Source: ...                    Exhibit 12    │
└─────────────────────────────────────────────┘
```

## MECE test

Before finalizing a section, ask:

- **Mutually exclusive** — no overlap between buckets?
- **Collectively exhaustive** — anything missing?

## Frameworks (use with purpose, not decoration)

| Framework | When |
|-----------|------|
| Issue tree | Break complex problem |
| 2×2 matrix | Prioritize options |
| Waterfall | Explain variance |
| Value chain | Cost or differentiation analysis |
| Porter five forces | Industry attractiveness |
| Customer journey | Experience gaps |

## Exhibit numbering

- Main flow: minimal exhibit refs
- Appendix: `Exhibit A-1`, `A-2` …
- Cross-reference in speaker notes

## Language

- Active voice, present tense for recommendations
- "We recommend" not "It is suggested"
- Quantify where possible; ranges with assumptions stated
