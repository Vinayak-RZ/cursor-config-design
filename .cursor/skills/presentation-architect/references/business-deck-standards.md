# Business presentation visual standards

Apply to **every** client-facing, investor, or board deck. This is the quality bar.

## Layout

| Rule | Value |
|------|-------|
| Aspect ratio | 16:9 (`LAYOUT_16x9`) |
| Safe margins | ≥ 0.5" all sides |
| Title zone | top 15–20% of slide |
| Max bullets | 5 per slide; prefer 3 |
| Min body font | 16pt (never below 14pt) |
| Title font | 28–36pt bold |
| Line spacing | 1.2–1.4 for bullets |

## Typography

- **Max 2 families:** one sans for UI (e.g. Plus Jakarta Sans, Inter, Arial), optional serif for cover only
- **Weight hierarchy:** bold titles, regular body, semibold for callouts
- **No ALL CAPS** except short labels (e.g. section dividers)

## Color

- **60-30-10:** ~60% background/neutral, 30% secondary, 10% accent
- Accent only for: CTA, key number, chart highlight, section divider
- Text contrast: WCAG AA minimum on all text/background pairs
- Pull brand hex from `design-systems/` when on-brand

## Charts

- **Chart title = insight sentence** ("MRR grew 3.2× in 12 months")
- Label axes; cite source in footnote
- Prefer bar, line, waterfall over pie (max 5 slices if pie)
- No 3D chart effects

## Slide types (master layouts)

| Layout | Use |
|--------|-----|
| `TITLE` | Section divider — one line + optional subtitle |
| `TITLE_AND_BODY` | Standard insight + bullets |
| `TITLE_AND_CHART` | Insight title + chart area (60% width) |
| `TWO_COLUMN` | Compare options, before/after |
| `FULL_BLEED_IMAGE` | Product screenshot, team photo — text overlay minimal |
| `QUOTE` | Customer testimonial — large quote, attribution |
| `CLOSING` | Thank you / contact / next steps |

## Consulting-specific

- **Action titles** — every slide title is a complete sentence stating the takeaway
- **So what box** — optional bottom strip on analysis slides
- **Source line** — 9–10pt footer: "Source: …; Company analysis"

## Quality checklist (before delivery)

- [ ] Every title states an insight, not a topic
- [ ] No slide with >40 words in body (excluding appendix)
- [ ] Consistent margins and alignment across deck
- [ ] Charts have units, time ranges, sources
- [ ] Speaker notes on every slide
- [ ] Appendix holds backup detail — not main flow
- [ ] File opens cleanly in PowerPoint and Google Slides
